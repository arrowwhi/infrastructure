# README

## Обзор

Этот проект представляет собой библиотеку для **маскировки данных**, которая позволяет скрывать чувствительную информацию в **форматах JSON**, **XML** и **in-memory структурах Go (`map[string]any`)**.
Библиотека поддерживает различные стратегии маскировки, такие как частичное скрытие номеров телефонов, номеров карт, паспортов и другой чувствительной информации. Пользователи могут настраивать поведение маскировщика с помощью регулярных выражений и заранее определенных правил для различных типов данных.

Библиотека реализует оптимизацию памяти при работе с большими объемами данных, используя пул буферов для повторного использования объектов `bytes.Buffer`, что позволяет снизить нагрузку на систему при множественных операциях маскировки.

## Особенности

- **Маскировка JSON**: Маскировка чувствительных данных в объектах и массивах JSON (потоковая обработка через `encoding/json.Decoder`).
- **Маскировка XML**: Маскировка чувствительных данных в элементах и атрибутах XML.
- **Маскировка Go-структур (`map[string]any`)**: Маскировка in-memory структур без сериализации.
- **Настройка правил**: Определение пользовательских правил для маскировки ключей и значений с использованием регулярных выражений.
- **Встроенные маскировщики**: Предопределенные маскировщики для телефонов, карт, паспортов, ИНН, ФИО, e-mail, константной замены и др.
- **Оптимизация памяти**: Использование пула буферов для оптимизации памяти при работе с большими объемами данных.

## Встроенные маскировщики (подробно)

| Тип        | Назначение         | Алгоритм (кратко)                                                                                                                          | Пример                                                                                 |
| ---------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| `phone`    | Телефон            | Если цифр < 7 → все `*`; иначе видимы **последние 4** цифры, разделители сохраняются                                                       | `+7 (999) 123-45-67` → `+* (***) ***-45-67`                                            |
| `card`     | PAN (номер карты)  | Если цифр < 16 → все `*`; иначе видимы **2 слева** и **4 справа**                                                                          | `4111111111111111` → `41**********1111`                                                |
| `passport` | Паспорт            | Ровно 10 цифр → видимы **4 слева** и **2 справа**; иначе все `*`                                                                           | `1234567890` → `1234****90`                                                            |
| `inn`      | ИНН                | Если цифр < 6 → все `*`; иначе видимы **2 слева** и **4 справа**                                                                           | `7712345678` → `77****5678`                                                            |
| `fullname` | ФИО/имя            | Каждая **руна** заменяется на `*`, **пробелы сохраняются**                                                                                 | `Иванов Иван` → `****** ****`                                                          |
| `misc`     | Общая маска        | Каждая **руна** (включая пробелы) заменяется на `*`                                                                                        | `abc 123` → `*******`                                                                  |
| `email`    | E-mail             | **Вся локальная часть** до `@` → `*`; если локаль **< 3 байт**, выводится **ровно 5** `*`; домен без изменений; не-email → fallback `misc` | `j@example.com` → `*****@example.com`, `john.doe@example.com` → `********@example.com` |
| `const`    | Константная замена | Если `ToPattern` пуст — все значение заменяется на `MaskVal` (по умолчанию `*****`); иначе совпадения `ToPattern` заменяются на `MaskVal`  | `ACC-12-3456-78` + `\d`→`*` → `ACC-**-****-**`                                         |

> Примечания:
> • Подсчёт для `email` выполнен в **байтах** (UTF-8): многобайтные символы дадут больше `*`.
> • Реализация e-mail не является полным парсером RFC 5322 (деление идёт по первому `@` после `TrimSpace`; кавычные локали/CFWS не разбираются).

## Семантика применения правил

**JSON**

- По **ключам**: при совпадении `KeyRules` для имени поля применяется соответствующий маскер к **значению**.
- По **значениям**: `ValRules` применяются к строкам (и числам/булевым/`null` под действием key-маски преобразуются в строку); строки экранируются корректно (`json.Marshal`).
- **Массивы**: key-маска **наследуется на элементы** массива; для вложенных объектов key-маска **не наследуется** — внутри ключи матчатся заново.

**XML**

- Маскируются **тексты узлов** и **значения атрибутов**. Сначала пытаемся матчить по имени тега/атрибута (`KeyRules`), затем — по значению (`ValRules`).

**Map (in-memory)**

- Поддержаны `map[string]any` и `[]any`.
- key-маска **наследуется на элементы срезов**, но **не наследуется** во вложенные `map`.
- `ValRules` применяются к `string` и `[]byte` (по строковому виду).
- Если замаскировано **нестроковое** значение, результат — `string`.
- Исходная карта остаётся неизменной; возвращается новая.

## Конфигурация

```go
type Config struct {
    KeyRules     []RuleConfig // правила по ключам
    ValRules     []RuleConfig // правила по значениям
    Enabled      bool         // включить маскирование
    IsJSONMasked bool         // применять к JSON
    IsXMLMasked  bool         // применять к XML
}

type RuleConfig struct {
    Type         string   // "phone"|"card"|"passport"|"fullname"|"inn"|"misc"|"email"|"const"
    FromPatterns []string // regex-строки для поиска ключей/значений
    ToPattern    string   // regex для подстановки (обычно для "const")
    MaskVal      string   // значение подстановки (по умолчанию "*****" для "const")
}
```

**Валидация и умолчания**

- `Enabled=true` и при этом `IsJSONMasked=false` и `IsXMLMasked=false` → **ошибка режима**.
- Должно быть **хотя бы одно** правило (в `KeyRules` или `ValRules`).
- Для `Type!=const` пустой `FromPatterns` → автозаполнение именем типа.
- Для `const` пустой `MaskVal` → `"*****"`.
- Для `const`: если `ToPattern` пуст — заменяется всё значение; иначе — только совпадения `ToPattern`.
- Ошибки агрегируются через `go-multierror`.

## Структура

- **masking**: Содержит основную логику маскировки.
  - **Masker**: Основной объект для применения правил маскировки JSON и XML.
  - **MapMasker**: Отдельный объект для маскировки in-memory структур (`map[string]any`, `[]any`).
  - **MaskerBuilder**: Строит и настраивает объект `Masker` с правилами и настройками.
  - **Config**: Содержит конфигурацию маскировщика, включая правила для ключей и значений.
  - **Маскировочные функции**: `maskPhone`, `maskCard`, `maskPassport`, `maskINN`, `maskFullname`, `maskMisc`, `maskEmail`, и т. д.
  - **Проверка данных**: Быстрая проверка JSON (`gjson.ValidBytes`) и корректный разбор XML через `encoding/xml`.

## Использование

### Основное использование (маскировка JSON и XML)

1. **Импорт**:

```go
import "github.com/arrowwhi/infrastructure/utils/masking"
```

2. **Конфигурация и сборка**:

```go
cfg := masking.Config{
    Enabled:      true,
    IsJSONMasked: true,
    IsXMLMasked:  true,
    KeyRules: []masking.RuleConfig{
        {Type: masking.Phone, FromPatterns: []string{`(?i)phone`}},
        {Type: masking.Card,  FromPatterns: []string{`(?i)card(number)?`}},
        {Type: masking.Email, FromPatterns: []string{`(?i)^email$|^e[-_]?mail$`}},
    },
    ValRules: []masking.RuleConfig{
        // PAN в тексте
        {Type: masking.Card,  FromPatterns: []string{`(?m)(?:\D|^)(\d{16,})(?:\D|$)`}},
        // E-mail как целая строка
        {Type: masking.Email, FromPatterns: []string{`(?i)^[a-z0-9._%+\-]+@[a-z0-9.\-]+\.[a-z]{2,}$`}},
    },
}
masker, err := masking.NewMaskerBuilder(cfg).Build()
if err != nil { log.Fatalf("build masker: %v", err) }
```

3. **Маскировка JSON**:

```go
in := []byte(`{
  "phone": "+7 (999) 123-45-67",
  "cardNumber": "4111111111111111",
  "email": "john.doe@example.com"
}`)
out, err := masker.Mask(in)
if err != nil { log.Fatalf("mask json: %v", err) }
fmt.Println(string(out))
// {
//   "phone": "+* (***) ***-45-67",
//   "cardNumber": "41**********1111",
//   "email": "********@example.com"
// }
```

4. **Маскировка XML**:

```go
in := []byte(`
<user>
  <phone>+7 (999) 123-45-67</phone>
  <cardNumber>4111111111111111</cardNumber>
  <email>j@example.com</email>
</user>`)
out, err := masker.Mask(in)
if err != nil { log.Fatalf("mask xml: %v", err) }
fmt.Println(string(out))
// <user>
//   <phone>+* (***) ***-45-67</phone>
//   <cardNumber>41**********1111</cardNumber>
//   <email>*****@example.com</email>
// </user>
```

### Маскирование in-memory структур (`map[string]any`)

`MapMasker` маскирует данные **без сериализации** — напрямую по структурам `map[string]any` и `[]any`.

**Особенности:**

- Те же `RuleConfig` и встроенные маскировщики.
- `IsJSONMasked`/`IsXMLMasked` **игнорируются**.
- key-маска **не наследуется** во вложенные `map`, но **наследуется** на элементы `[]any`.
- Маскирование нестроковых значений → результат **`string`**.
- Возвращается **новая** карта, исходная не изменяется.

**Пример:**

```go
cfg := masking.Config{
    Enabled: true,
    KeyRules: []masking.RuleConfig{
        {Type: masking.Phone,    FromPatterns: []string{`(?i)phone|mobile`}},
        {Type: masking.Card,     FromPatterns: []string{`(?i)card(number)?`}},
        {Type: masking.Fullname, FromPatterns: []string{`(?i)full_?name`}},
        {Type: masking.Const,    FromPatterns: []string{`(?i)password|token|secret`}, MaskVal: "*****"},
        {Type: masking.Email,    FromPatterns: []string{`(?i)^email$`}},
    },
    ValRules: []masking.RuleConfig{
        {Type: masking.Card, FromPatterns: []string{`(?m)(?:\D|^)(\d{16,})(?:\D|$)`}},
        {Type: masking.Email, FromPatterns: []string{`(?i)^[a-z0-9._%+\-]+@[a-z0-9.\-]+\.[a-z]{2,}$`}},
    },
}
mm, err := masking.NewMapMasker(cfg)
if err != nil { log.Fatalf("build map masker: %v", err) }

in := map[string]any{
  "full_name": "Иванов Иван Иванович",
  "phone":     "+7 (999) 123-45-67",
  "email":     "j@example.com",
  "nested": map[string]any{
    "mobile": "89991234567",
    "secret": "abcd-1234-efgh",
    "arr":    []any{"4111111111111111", true, 42},
  },
}
out, err := mm.MaskMap(in)
if err != nil { log.Fatalf("mask map: %v", err) }
b, _ := json.MarshalIndent(out, "", "  ")
fmt.Println(string(b))
// {
//   "full_name": "****** **** ********",
//   "phone": "+* (***) ***-45-67",
//   "email": "*****@example.com",
//   "nested": {
//     "mobile": "*******4567",
//     "secret": "*****",
//     "arr": ["41**********1111", true, 42]
//   }
// }
```

## Обработка ошибок

Библиотека возвращает ошибки в случае некорректных конфигураций или если встречается неподдерживаемый формат данных. Примеры:

- **Некорректная конфигурация**: отсутствуют `KeyRules` и `ValRules`, либо `Enabled=true` без включения JSON/XML — билдер агрегирует ошибки и возвращает одну.
- **Неподдерживаемый формат данных**: если вход не является корректным JSON/XML при соответствующих флагах, вернётся ошибка `unsupported data format for masking`.

```go
cfg := masking.Config{
   Enabled:      true,
   IsJSONMasked: false,
   IsXMLMasked:  false,
}
_, err := masking.NewMaskerBuilder(cfg).Build()
if err != nil {
   fmt.Println("Ожидаемая ошибка:", err)
}
```

## Примечания и ограничения

- Реализация **не является полным парсером RFC 5322** для e-mail (кавычёные локали, CFWS, домены-литералы не разбираются).
- Подсчёт длины локали для e-mail — в **байтах** (UTF-8).
- `MapMasker` применяет `ValRules` к `string`/`[]byte`; частичные совпадения в составных типах без сериализации не поддерживаются.
- Объекты `Masker` и `MapMasker` иммутабельны после сборки и потокобезопасны; буферы берутся из пула и возвращаются обратно при `Cap() ≤ 4096`.
